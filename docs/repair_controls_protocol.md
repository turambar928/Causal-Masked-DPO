# 错误历史与难度混杂：冻结后续诊断协议

本轮由用户授权完成上轮报告建议中的两个前置检验：匹配错误历史控制，以及修复收益相对 C/F 难度估计的增量预测价值。不修改论文，不调用模型 API，不微调语言模型，不自动扩展到自然错误采集或训练。

本轮复用已经查看过的 96 道题及 192 场景，做独立新采样，是针对上轮现象的探索性后续诊断，不是新题泛化或独立确认性研究。配置、分析代码和门槛在新采样开始前冻结。旧源码、数据、预测及验证记录不变。

## 四条件干预

| 条件 | 原始目标步骤 | 追加内容 |
|---|---|---|
| CC | 正确 | `Correction: the previous step was incorrect. It should be: {正确步骤}` |
| WC | 错误 | 与 CC 完全相同的纠正文本；与上一轮 R 的输入完全相同 |
| CN | 正确 | `Review: the calculation is: {正确步骤}` |
| WN | 错误 | 与 CN 完全相同的中性复核文本 |

每个句式内仅改变历史步骤的计算结果，最终给出的正确步骤相同。CN/WN 是主要对照；CC 错误声称先前正确的步骤有错，因此 CC/WC 只作次要检查，不能单独支持错误历史机制。

实际 tokenizer 的输入长度检查显示 189/192 场景两种句式下均精确等长，另 3 场景差 1 token。保留全体场景作为主分析，并事先固定等长子集的敏感性分析；不根据结果决定丢掉哪些题。跨句式的文本长度和语义均不同，交互项不能被解释为纯粹某个词的效应。

同一冻结 Qwen2.5-0.5B-Instruct，bf16、SDPA、batch32、temperature=.7、top_p=.95、top_k=0、repetition_penalty=1.1、512 新 token，EOS 使用 tokenizer EOS ID；chat assistant 前缀不附 EOS。每场景四条件×8 次为一批，两批独立 seed，总计 384 批、12,288 条新续写。seed=20261002，批次 ID 与上轮不同。复用上轮全部 13,824 条已验证续写，无额外 C/F 采样。

## 主比较与预测任务

两个预先固定的主要量：

1. 中性错误历史差值 `CN-WN`，正值表示即使最终得到同样正确复核，错误历史组仍较差。
2. 预测上述新差值时，在 C/F 难度基线之外加入旧 `(R-S)` 的整题留出 MSE 改善，正值表示改善。

按模板分层、题目聚类 bootstrap 10,000 次，保留同题两位置，两个主区间各 97.5%，作 Bonferroni 调整。CC−WC、两种句式的历史差值之差、CN−旧 C、WC−旧 R、精确等长子集为次要描述性分析，95% 区间不作确认性解释。

### 预测如何避免泄漏

- 4 折，每种模板的 16 题按固定哈希顺序均分，每折每模板 4 题；同题两个位置永远同折。分组在新生成前写入数据文件。
- 历史特征全部来自上一轮采样：C、F、它们的平方及乘积；再加入模板×位置 one-hot、CN 输入 token 数、WN−CN 输入长度差、±1 扰动方向、正确目标结果绝对值的 log1p。
- 三个统计回归器：基线；基线＋旧 R−S；基线＋旧 R。后者检验所谓修复收益是否只是旧 R 成功率的近似重命名。
- 所有回归器固定 ridge alpha=10，最小化训练样本平方误差和加 L2 惩罚；截距不惩罚。特征均值/标准差只在训练折拟合，无调参。预测差值裁剪至 [-1,1]，成功率裁剪至 [0,1]。
- 主目标为新 CN−WN 两采样批次的平均值；另把新 WC 成功率作为次要预测目标，避免把“更会预测修复后可解性”误写成“更会预测历史损害”。模型均只拟合其他题目的目标。
- 保存每折 train/test 行索引、标准化参数、系数、逐场景特征、OOF 预测与两个采样批次的目标。
- MSE 差区间按题目重采样已固定的 OOF 误差，没有每次重新拟合回归，因此不涵盖全部拟合变异，是条件性的探索估计。同一组 OOF 预测分别对两批目标评分；这不是两次独立训练验证。
- 所有预测器共享同样的历史采样预算。C/F 和修复特征均需要带答案验证的 rollout，不宣称它们是部署时免费或 oracle-free 的信号。

## 决策与停止条件

- 任一新条件截断率 >5%：协议不可解释；CN 成功率 <20%：当前控制下能力不足。哈希、数据、判分或配对有误则直接验收失败。
- 历史效应门槛：主 CN−WN 区间下界 >0，均值至少 3 个百分点，且等长子集 95% 区间下界 >0。
- 额外信息门槛：主 MSE 改善区间下界 >0，相对基线 MSE 至少改善 5%，且同一 OOF 预测对两个独立采样批次评分都改善。
- 两者通过：仅支持进一步研究；历史效应通过但额外信息不通过：不支持据此做自适应权重；只有预测改善：不能补救历史主假设未获支持；都不通过：停止把当前信号推进为新目标。

这些是研发投入门槛，不是原创性或学习收益标准。无论结果如何，不自动开始自然错误采集或语言模型训练；应先如实交付本轮诊断，再决定是否扩大范围。

## 运行与验收

```bash
OMP_NUM_THREADS=4 .venv/bin/python -m pytest -q
.venv/bin/python scripts/repair_controls.py prepare
.venv/bin/python -u scripts/repair_controls.py rollout --gpu 3 --max-jobs 1
.venv/bin/python -u scripts/repair_controls.py rollout --gpu 3
.venv/bin/python scripts/repair_controls.py analyze
```

prepare 拒绝覆盖已有目录；冻结模型、前次预测及验证记录、全部相关计算源码、新数据/分折和配置。单 worker 锁、原子写入、完成批次验证后跳过、失败批次按同一随机种子整批恢复。显存不足停止，不擅自改变 batch、精度或模型，不终止其他进程。

验收要求完整 384 批，逐题重判、输出 token 与文本一致、输入 token 哈希一致、矩阵无重复/缺失、历史预测完整可用、条件构造和分折可重建、训练/测试题 ID 不交叉。旧实验历史验证文件不覆盖。
