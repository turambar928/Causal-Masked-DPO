# 修复预检的已有工作核查（技术记录，不修改论文）

核查日期：2026-09-30。只读取公开 arXiv 页面及 HTML 正文，没有调用任何模型 API。以下是指定方向的代表性工作核查，不是截至 2026 年的穷尽检索；不能据此证明不存在更接近的方法。

## 已核实的重合

| 工作与来源 | 核实内容 | 对候选方向的约束 |
|---|---|---|
| [Step-DPO](https://arxiv.org/abs/2406.18629)，[正文](https://arxiv.org/html/2406.18629) | §3.1 在同一正确前缀后比较正确与错误下一步骤；§3.2 包含错误收集、定位、修正，修正数据通过续写并筛选最终答对的样本获得。 | “同前缀＋修复步骤＋局部 DPO”已有直接先例，不是新贡献。后续必须以普通局部 DPO 作强对照。 |
| [Math-Shepherd](https://arxiv.org/abs/2312.08935)，[正文](https://arxiv.org/html/2312.08935) | §3.3 自动过程标注使用多次 completion；hard estimation 按是否能得到正确答案标注，soft estimation 使用正确完成的频率。 | “用后续成功率评价中间步骤”不是新颖点；成功率受 completer 能力影响，不等于数学正确性。 |
| [OmegaPRM](https://arxiv.org/abs/2406.06592)，[正文](https://arxiv.org/html/2406.06592) | §3 的 Monte Carlo / MCTS 过程标注与二分搜索定位首次错误，强调高效生成过程监督；正文明确讨论自动过程标注噪声。 | 不能把 rollout＋首次错误定位包装为创新；采样成本和定位/估值噪声必须显式比较。 |
| [RISE](https://arxiv.org/abs/2407.18219)，[正文](https://arxiv.org/html/2407.18219) | §4 将单轮问题转成多轮 MDP，通过数据采集和微调学习在失败回答之后改进；可利用环境反馈。 | “从已有错误中学习恢复／多轮改进”已有先例。我们的单条 assistant 内外部纠正不是同一评测协议，不能直接比较数字。 |
| [SCoRe](https://arxiv.org/abs/2409.12917)，[正文](https://arxiv.org/html/2409.12917) | 摘要及正文指出离线纠正轨迹 SFT 的分布不匹配与行为坍缩问题，提出多轮在线 RL、初始阶段及鼓励纠错的奖励机制。 | 获得修复轨迹不等于学会自纠错；必须区分外部提供正确修复、模型主动产生修复、训练后自由生成收益。 |

本文献读取中出现的其他模型名称只是原论文内容，不表示本项目调用了这些模型。本轮实验只运行本地 Qwen。

## 本轮实际检验什么

本轮比较替换目标步骤、保留错误后再显式纠正、以及假修复提示，对同一个冻结 Qwen 后续正确率的影响。通过同题干预、独立采样复核与分层配对统计，检查是否存在值得进一步研究的信号。

它不是新的训练算法，也没有证明：

- 模型能够自行找到错误或产生正确修复；
- 按修复收益选择训练数据优于普通采样；
- “预防／恢复”自适应分配优于固定比例混合；
- 超越局部 DPO、过程价值估计、已有自纠错训练；
- 在真实模型错误、真实数学任务或更大模型上成立。

## 只有后续证据才能支撑的候选区别

可能继续研究的点是：在等数据、等采样/训练预算下，使用经过独立复核的干预收益，决定不同错误应分配多少预防监督和恢复监督。但本轮的门槛只检查修复信号，并不直接测量这种分配的学习价值。

即便通过预检，下一阶段仍必须先核查更近期的干预式 credit assignment、错误恢复偏好优化和课程/数据选择工作，再用同数据修复 SFT、普通局部 DPO、固定预防/恢复混合作为基线。不能把“模块组合”本身视作原创性证明。
