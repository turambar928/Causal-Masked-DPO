# 续写协议校准结果：候选未达标，独立验证未启动

运行日期：2026-10-02。本轮执行用户确认的“开发题校准＋通过后独立验证”方案；按冻结停止规则结束，没有调整提示或追加采样。

## 结论

两个候选续写协议都未通过开发门槛，冻结决策为 `calibration_failed`，`selected=null`。无追加文本的正确历史续写准确率为 60.03%；状态复述为 39.19%，状态复述＋继续指令为 21.74%。旧 Review 条件为 26.04%，在新开发题上再次出现大幅下降。

因此，本轮不能提供新的错误历史效应或自适应权重证据。它说明：在当前 0.5B 模型、assistant 内追加文本的形式与这些合成题上，这两种预设替代提示没有解决测量干扰。不能把该阴性校准结果解释成“错误历史没有影响”，也不能推广为所有纠错协议无效。

## 开发集结果

以下均为冻结开发集上的描述性统计，不作为选中协议的独立确认性检验。

| 条件 | 正确数/总数 | 准确率 | 相对 base（百分点） | 平均生成 token | 截断率 |
|---|---:|---:|---:|---:|---:|
| base：不追加 | 461/768 | 60.03% | — | 77.58 | 0.13% |
| review：旧 Review | 200/768 | 26.04% | −33.98 | 72.82 | 0.00% |
| state：状态复述 | 301/768 | 39.19% | −20.83 | 69.64 | 0.00% |
| continue：状态复述＋继续指令 | 167/768 | 21.74% | −38.28 | 115.88 | 0.65% |

候选必须同时满足：准确率至少 40%、较 base 下降不超过 5 个百分点、截断率不超过 5%。本次相对 base 的要求实际上是至少达到 55.03%。state 不仅略低于 40%，更远低于相对基线门槛；continue 也同时不满足两项准确率条件。失败不能被解释成仅仅卡在一个接近的绝对阈值上。

两候选的截断率都合格，因此不是因截断规则而停止。但低截断率不证明推理过程完整。

### 格式与中间值答案代理

| 条件 | 显式答案标记率 | 解析答案等于目标中间值的比例 |
|---|---:|---:|
| base | 22.66% | 5/768 = 0.65% |
| review | 55.99% | 95/768 = 12.37% |
| state | 30.34% | 45/768 = 5.86% |
| continue | 69.01% | 28/768 = 3.65% |

“显式答案标记”沿用 `####` 或 `\boxed{` 检测；准确率仍使用现有答案解析器，也接受没有显式标记的答案。增加答案标记并不等于增加正确率：continue 的标记率最高、输出最长，但准确率最低。

中间值代理只在目标正确中间值不同于真实最终答案的输出上计算，本次各条件均有 768 条适用。它不是系统人工核验，也不能证明所有匹配都由“提前结束”造成，更不能覆盖所有遗漏运算或过程错误。判分仅使用模型新生成文本，不拼接给定正确前缀。

- 单实验锁拒绝并发入口；结束后的开发恢复检查跳过全部已完成批次，不重新生成。旧实验源码、数据、模型与历史结果保持冻结。

## 对下一步的影响

不应继续对这两种提示追加采样，也不应将其直接接入新的自适应损失。当前更有价值的问题是：**如何构造既提供同等正确状态、又不严重改变正确历史续写行为的干预？**

后续可单独设计“原位替换目标步骤”与“保留错误后追加状态”的结构性对照，或研究独立对话轮次的反馈形式，而不是在当前结果上不断换句式挑高分。这些方案改变了被测问题；原位替换会移除错误历史，不能单独证明保留历史后的损害。需另行冻结协议、开发/验证划分和预算，本轮没有自动执行。

即使未来校准成功，还需重新检验自然错误、超越难度的增量信号及学习收益。上轮 4.04 个百分点的历史差值仍受其原协议局限约束，本轮没有确认或推翻它。
